# AxAI — Десктопный диктофон на Python + PySide6

AI диктофон-помощник с трекером дедлайнов для студентов.

## Быстрый запуск на вашем компьютере

### 1. Создание виртуального окружения (рекомендуется)
```bash
python -m venv venv

# На Windows:
venv\Scripts\activate

# На macOS / Linux:
source venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python main.py
```

---

## Возможности десктопного приложения

1. **Запись лекций**: Захват с микрофона, пауза, таймер, сохранение в WAV.
2. **Импорт PDF**: Загрузка методичек, конспектов и лекций с автоматическим добавлением в базу.
3. **Трекер дедлайнов**: Чеклист всех домашних заданий и сроков сдачи из всех лекций.
4. **Управление памятью**: Быстрое удаление тяжелых аудиозаписей с сохранением текста конспектов.
5. **Экспорт**: Сохранение конспектов в Markdown, pdf и latex.
