# Lectura AI — Десктопный диктофон на Python + PySide6 (Qt6)

Полноценное автономное приложение для студентов на **Python 3.10+** и **PySide6**.

## 🚀 Быстрый запуск на вашем компьютере

### 1. Создание виртуального окружения (рекомендуется)
```bash
python -m venv venv

# На Windows:
venv\Scripts\activate

# На macOS / Linux:
source venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python main.py
```

---

## 📁 Структура проекта

- **`main.py`**: Главное окно приложения (PySide6 / Qt6), боковая панель, экраны записи, истории, дедлайнов, памяти, настроек и профиля.
- **`pdf_importer.py`**: Модуль извлечения текста из PDF файлов (`pypdf`) и автоматического выделения домашних заданий.
- **`audio_worker.py`**: Фоновый захват аудио с микрофона (`sounddevice`) и транскрибация (`faster-whisper`) в отдельном потоке `QThread`.
- **`requirements.txt`**: Список всех библиотек.

---

## 🛠️ Возможности десктопного приложения

1. **Запись лекций**: Захват с микрофона, пауза, таймер, сохранение в WAV.
2. **Импорт PDF**: Загрузка методичек, конспектов и лекций с автоматическим добавлением в базу.
3. **Трекер дедлайнов**: Чеклист всех домашних заданий и сроков сдачи из всех лекций.
4. **Управление памятью**: Быстрое удаление тяжелых аудиозаписей с сохранением текста конспектов.
5. **Экспорт**: Сохранение конспектов в Markdown (`.md`).
